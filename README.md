# FairSing AI 5.1 Professional

手機／平板優先的 AI 音樂評量平台。

## 5.1 重點
- 一般班級考試、音樂班術科、歌唱比賽三套評分標準。
- 歌唱、中音直笛、節奏打擊、鍵盤與其他樂器採不同評量邏輯。
- 歌曲長度支援自動判斷、手動分秒輸入與不評完整度。
- 歌唱加入換氣與發音清晰度參考。
- 直笛加入運舌、氣流與換氣參考。
- 節奏打擊不評音準。
- AI 評語與信心值僅供教師參考，教師保有最後決定權。

部署方式請參閱 `FIREBASE_DEPLOY.md`。


## Curriculum 智慧課程規劃
- 保留原有匯入教學進度表與手動新增週次。
- 新增多檔課程內容上傳：PDF、DOCX、PPTX、XLSX/XLS/CSV、TXT/MD、JPG/PNG/WEBP。
- 讀取教材後依 20～22 週自動建立主題、學習目標、活動、SEL／議題與評量。
- 產生前可預覽與逐週修改，再選擇覆蓋、填空白或保留現有內容補足。
- 圖片 OCR 與 PDF/Word/PPTX 解析需網路載入瀏覽器元件。
